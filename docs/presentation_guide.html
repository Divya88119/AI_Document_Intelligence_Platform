📦 3. Module-by-Module Technical Deep Dive

Module 1: Authentication, RBAC & Security
Core Security
JWT Bearer BCrypt.Net Claims-Based RBAC EF Core Seeder
  • Token Security: Generates HMAC-SHA256 signed JWT tokens encapsulating User ID, Email, and Role (Admin, User).
  • Password Security: One-way password hashing using BCrypt.Net (salt work factor = 11).
  • Auto-Seeding & Migration: InitialAdminSeeder applies pending EF Core migrations on application startup and seeds default admin credentials without manual database intervention.
Module 2: Multi-Format Extraction Engine
Document Parsing
PdfPig (PDF) DocumentFormat.OpenXml (.docx/.xlsx) UTF-8 Decoders
  • PDF Extraction: Uses PdfPig to iterate page-by-page, extracting textual flow, headers, and paragraph blocks.
  • Word & Excel Processing: Uses OpenXML to traverse body elements and shared string tables, transforming spreadsheets into structured CSV rows.
  • Extracted Content Record: Stores raw text, total word count, total page count, and timestamp in DocumentExtractedContent.
Module 3: Asynchronous Background Processing Pipeline
High Concurrency
System.Threading.Channels BackgroundService State Machine
  • Non-Blocking Ingestion: The upload endpoint writes the file, enqueues the document ID to a bounded channel, and returns HTTP 201 in under 50ms.
  • Background Worker: DocumentProcessingWorker continuously consumes the queue, executing extraction and AI intelligence asynchronously.
  • Crash Resilience: On server restart, the worker automatically scans SQL Server for pending/unprocessed documents and re-queues them.
Module 4: AI Document Intelligence & Structuring
AI / NLP Core
Google Gemini OpenAI Offline Heuristic Engine JSON Schema
  • Multi-Engine Fallback: Calls primary cloud LLM APIs, but seamlessly falls back to a built-in offline NLP engine if keys are missing or offline.
  • Structured Extraction: Outputs category classification, confidence score, executive summary, key highlights, monetary totals, dates, and action items.
Module 5: Semantic Q&A & Document Chat Studio
Conversational AI
Prompt Grounding Zero Hallucination Constraints Chat History Persistence
  • Grounded Context: Injects the verified extracted text directly into the LLM system prompt as the sole source of truth.
  • Hallucination Defense: Enforces strict system prompt instructions: "Answer strictly using the document context. If the document does not contain the answer, explicitly state that it is not present."
Module 6: Automated Data Analytics & Predictive Engine
Data Science & ML
Data Profiler IQR Outlier Detection Pearson Correlation Time-Series Regression
  • 1. Data Profiling & Health Audit: Inferred data types (Numeric, DateTime, Categorical), cardinality, null count, duplicates, and Data Health Score (0–100%).

🎤 4. Top Interview Questions & Model Answers

Q1 Why did you use System.Threading.Channels instead of processing files synchronously inside the controller?
"Document parsing, OCR, and AI analysis take several seconds per file. If executed synchronously, the web server's thread pool would become exhausted under high traffic, leading to thread starvation and HTTP 504 gateway timeouts. By using System.Threading.Channels.Channel<int>, the upload API immediately saves the binary, marks the record as Queued, and responds in under 50ms. The background worker consumes jobs asynchronously with thread safety and backpressure."
Q2 How does your automated data cleaning and imputation pipeline work?
"When a raw CSV or Excel dataset is ingested:
1. Deduplication: Generates row hash signatures and removes exact duplicate records.
2. Type Inference: Profiles each feature as Numeric, DateTime, Categorical, or Free Text.
3. Missing Value Imputation: Numeric features are imputed with the column median (which is robust against extreme outliers), and categorical missing cells are standardized to 'Unknown'.
4. Outlier Detection: Computes the Interquartile Range ($IQR = Q3 - Q1$) and flags anomalies outside $[Q1 - 1.5 \times IQR, Q3 + 1.5 \times IQR]$."
Q3 How does your predictive forecasting algorithm work?
"We use time-series regression extrapolation. We compute the linear slope ($m$) and intercept ($c$) from historical points using least-squares regression ($y = mx + c$) and project values across future horizons ($t+1, t+2, \dots, t+n$). To communicate uncertainty, we calculate the standard error of regression and construct 95% confidence intervals ($1.96 \times \text{Standard Error}$), providing upper and lower bounds alongside the projected growth rate ($\Delta\%$)."
Q4 How do you prevent hallucinations in the Document Chat Studio?
"We use grounded prompt engineering. The document's verified extracted text is injected directly into the system prompt as reference ground truth. We enforce strict negative constraints: 'Answer the question strictly using only the provided document text. If the answer is not mentioned, explicitly state that it is not present.' We also set temperature low (0.1–0.2) to prioritize factual precision."
Q5 Why did you use AsNoTracking() in Entity Framework Core queries?
"In read-only endpoints (such as fetching reports, listing documents, or calculating dashboard statistics), EF Core's change tracker is unnecessary. .AsNoTracking() bypasses identity resolution and snapshot tracking, significantly reducing memory allocations and improving query execution speed."
